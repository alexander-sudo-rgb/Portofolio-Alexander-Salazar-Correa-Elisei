# Visuels des projets

Les images sont conservées ici pour être versionnées avec le portfolio. Le dossier
`docs/` et les trois dépôts Epitech clonés sont des références locales ignorées par Git.
Chaque miniature du portfolio peut être ouverte en taille originale.

- `cvrie.png` : exemples de radiographies des classes NORMAL et PNEUMONIA, extraits des résultats enregistrés de `supervised_learning.ipynb` dans le dépôt CVRIE.
- `codename.png` : capture d’un extrait du véritable `Modelfile` et de la liste des fichiers de prompts du dépôt Codename, présentés dans une vue de code. Aucun résultat d’exécution n’est simulé.
- `starttrek.png` : graphique `figures/ppo_vs_dqn.png` du dépôt StartTrek, comparant les agents DQN et PPO. Le projet reste indiqué en cours.
- `nextbuy.png` : graphique ROC comparant régression logistique et Random Forest, extrait des résultats enregistrés du [notebook NextBuy](https://github.com/alexander-sudo-rgb/NextBuy/blob/main/B-DAT-201-PAR-2-1-nextbuy-23-main/notebook.ipynb).
- `tardis.png` : évolution des retards moyens, extraite des résultats enregistrés du [notebook d’analyse TARDIS](https://github.com/alexander-sudo-rgb/TARDIS-SNCF-Delay-Predictor/blob/main/B-DAT-200-PAR-2-1-tardis-16-main/tardis_eda.ipynb).
- `bookworm.png` : capture de l’[interface HTML Bookworm](https://github.com/alexander-sudo-rgb/Bookworm/blob/main/B-AIA-200-PAR-2-1-aliceinwonderland-8-main/Front-end/index.html), affichée localement avec le livre 11 sélectionné, sans résultats simulés.
- `hackathon.png` : capture du [composant d’accueil EcoCité](https://github.com/alexander-sudo-rgb/Poduct-Design-Hackathon/blob/main/my-climate-app/app/page.tsx), rendu localement avec les styles Tailwind du projet, sans données simulées ajoutées pour la capture.
- `juice-shop.png` : [capture officielle OWASP Juice Shop](https://github.com/juice-shop/juice-shop/blob/master/screenshots/screenshot01.png), utilisée pour illustrer l’application cible du projet de pentesting. Voir la licence associée dans `juice-shop-LICENSE.txt`.
